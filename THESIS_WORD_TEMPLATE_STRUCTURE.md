# Thesis Word Template Structure For This Project

This file converts the structure of [FinalThesis_Template.docx](FinalThesis_Template.docx) into a practical template outline for your thesis.

## 1. Word Template Formatting Rules

Use these page and paragraph settings from the Word template:

- Page size: A4
- Margins: 2.5 cm on top, right, bottom, and left
- Binding margin / gutter: 5 mm
- Header distance: about 1.25 cm
- Footer distance: about 1.25 cm
- Main body font: Times New Roman, 12 pt
- Main body alignment: justified
- Main body line spacing: 1.5 lines
- Main body first-line indent: about 0.7 cm
- Paragraph spacing after body text: 6 pt

Heading styles from the template:

- Heading 1: 14 pt, bold, left aligned, space before 18 pt, space after 6 pt
- Heading 2: 13 pt, bold, left aligned, indented under numbering structure
- Heading 3: bold, slightly smaller, used only when necessary
- Unnumbered major headings: same visual level as Heading 1

Important template rule:

- Use decimal numbering only up to 3 levels.
- `Introduction`, `Conclusions`, `List of Figures`, `References`, and `Attachments` are unnumbered in the template.

## 2. Formal Thesis Order From The Word Template

The Word template expects this order:

1. Inner title page
2. Thesis or diploma assignment sheet copy
3. Table of Contents
4. Introduction - unnumbered
5. Main thesis chapters - numbered
6. Conclusions - unnumbered
7. One-page foreign-language summary if required by university rules
8. List of Figures - unnumbered
9. References - unnumbered
10. Attachments / Appendices - unnumbered

## 4. Practical Word Style Mapping

When editing in Word, map your content like this:

- `Introduction`, `Conclusions`, `Summary`, `List of Figures`, `References`, `Attachments`: use the unnumbered heading style
- Main chapter titles such as `1.`, `2.`, `3.`: use Heading 1 style
- Subsections such as `3.1`, `3.2`: use Heading 2 style
- Sub-subsections such as `3.2.1`: use Heading 3 style
- Main paragraphs: use normal thesis body style
- Bullet lists: use the thesis bullet style, not manual dashes
- Figure captions: use a dedicated caption style below the figure
- Table captions: use a consistent caption style above or below the table based on faculty preference
- Source code blocks: single-spaced, visually separated, short blocks only in body chapters
